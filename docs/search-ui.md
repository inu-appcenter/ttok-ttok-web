# 연구실 검색 UI (TTOK-64)

TTOK-63에서 구현한 검색바·분야/학과 드롭다운과 URL/API 계약을 재사용한다.

## 결과와 상태

- 결과 건수는 서버의 `totalElements`를 사용한다. 1/2/3열 카드 배치와 같은 행의 높이를 맞춘다.
- 태그·소개가 없는 카드는 해당 내용을 비워 두며 가짜 태그나 준비 중 안내를 추가하지 않는다.
- `app/search/loading.tsx`가 실제 라우트 진입의 로딩 상태를 제공한다. 기존 카드 스켈레톤을 사용하고 로딩 중 검색 컨트롤은 비활성화한다.
- 조회 실패는 오류 화면으로, 성공한 0건 응답은 빈 결과 화면으로 표시한다. 다시 시도 버튼은 `router.refresh()`로 현재 URL의 서버 데이터를 다시 조회한다.
- 전체 건수가 있지만 현재 페이지가 비어 있으면 조건을 유지한 첫 페이지 이동을 제공한다. 이 경우 검색 결과 자체가 0건인 것으로 안내하지 않는다.

## 빈 결과의 대체 카드

- 키워드/분야 검색의 전체 건수가 0건이면 일반 목록 API의 첫 페이지를 추가 조회한다.
- 서버 기본 정렬 순서에서 최대 3개의 실제 연구실을 표시한다. 개인화·인기순·검색어 연관성 추천 API는 사용하지 않는다.
- 정상 검색 결과의 건수에 대체 카드를 합산하지 않는다. 개별 카드는 기존 연구실 상세 페이지로 이동한다.
- 일반 목록도 비어 있거나 조회에 실패하면 대체 카드 영역을 숨긴다. 더미 데이터를 넣지 않는다.

## 키보드와 모바일

- 분야/학과 버튼에서 위·아래 방향키로 열 수 있다. 분야는 검색 입력, 학과는 선택한 학과 항목으로 포커스를 옮긴다.
- 분야 검색 입력의 아래 방향키는 분야 선택으로 이동한다. 항목의 방향키와 Home/End로 이동하고 Enter/Space로 선택한다.
- 학과 목록에서는 좌·우 방향키로 단과대·학과 사이를 이동한다. 단과대에 포커스하면 해당 학과 목록을 갱신한다.
- 선택·Escape 닫기는 검색바 버튼에 포커스를 돌려준다. Tab으로 밖에 나가거나 외부를 클릭하면 드롭다운을 닫는다.
- 320·375·768·1440px의 결과/빈 결과 및 드롭다운을 검증한다. 신규 모바일 홈 시트 디자인은 포함하지 않는다.

## 남은 API 범위

분야 목록의 비로그인 403과 상위 분야 복합 조건은 기존 처리 범위를 유지한다. TTOK-65에서 학과 단독·학과+키워드 검색을 최신 API에 연결했으며, 학과 조건을 URL과 검색바에 복원한다. 드롭다운의 기존 예시 분류는 유지한다.
