# 정책 페이지

- `/terms`: 이용약관 4개 장, 19개 조항 및 부칙
- `/privacy`: 개인정보 처리방침 전문 및 15개 조항
- 시행일: 두 문서 모두 2026년 9월 9일

사용자가 제공한 `TTOK TTOK 이용약관.md`, `TTOK TTOK 개인정보처리방침.md`의 최신 본문을 반영했다. 이전 버전, 개정안 표시, 배포 전 편집 메모, 변경 사항 및 구현 체크리스트는 게시 본문에서 제외했다.

개인정보 처리방침 제3조의 미확정 항목은 사용자 답변에 따라 확정했다.

- AI 추천 입력 텍스트: 추천 생성 후 지체 없이 파기(별도로 저장하지 않음)
- 부정 이용 기록: 현재 수집하지 않음

## 구성 및 변경 위치

루트 `app/terms/page.tsx`, `app/privacy/page.tsx`는 라우트와 메타데이터만 정의한다. 본문은 `src/_pages/policy/ui/terms-page.tsx`, `privacy-page.tsx`에 있고, 두 문서의 읽기 화면은 같은 슬라이스의 `policy-page.tsx`를 사용한다.

정책 문서는 Server Component로 렌더링하며 별도 데이터 요청, Markdown 파서, 클라이언트 상태를 추가하지 않는다. 공통 헤더의 인증 쿠키 조회를 유지하므로 Next.js 빌드에서는 두 경로가 동적 서버 렌더링으로 표시되지만, 정책 본문에는 사용자 데이터 API가 필요 없다.

기존 Footer의 `/terms`, `/privacy` 링크를 그대로 사용한다. 페이지 상단의 문서 이동 링크는 모바일에서도 제공한다. 접을 수 있는 목차는 HTML `details`를 사용하며 조항 앵커로 이동한다. 표는 좁은 화면에서 표 영역 안에서만 가로 스크롤할 수 있고 키보드 포커스를 지원한다.

본문을 수정할 때에는 문서뿐 아니라 목차, 시행일 표시, 라우트 메타데이터도 함께 확인한다. 정책 내용의 변경은 운영팀이 제공한 확정본을 기준으로 한다.
